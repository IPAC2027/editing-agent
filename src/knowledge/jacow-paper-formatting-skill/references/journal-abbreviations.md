# Selected journal abbreviations (Annex C, ISO 4)

Use the abbreviation in the reference list. Obvious typos in the guide's printed table were corrected in the full names (and a few abbreviations got missing trailing periods). For journals not listed, use the ISO 4 sources: https://marcinwrochna.github.io/abbrevIso/ and https://woodward.library.ubc.ca/researchhelp/journal-abbreviations/.

Note: the guide's own sample reference writes Optics Express in full; the table gives Opt. Express - prefer the abbreviation.
