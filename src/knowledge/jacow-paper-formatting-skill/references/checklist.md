# Pre-submission checklist (from the guide, plus checks implied by its rules)

Official checklist:
- [ ] Only Times/Times New Roman (standard, bold, italic) and Symbol fonts; text 10 pt, references 9 pt, DOIs/URLs Liberation Mono 8 pt. Hyperlinks only on DOIs.
- [ ] Figures use Times/Times New Roman/Symbol where possible, fonts embedded.
- [ ] Citations appear in sequential order and every reference is cited.
- [ ] References complete, DOIs appended where they exist, IEEE style per Annex B.
- [ ] PDF prints correctly.
- [ ] No page numbers.

Layout:
- [ ] 595 x 792 pt page; margins 19/19/20/20 mm; two columns 82.5 mm, 5.3 mm gap.
- [ ] Title (14 pt bold caps) and author block full width, centered.
- [ ] Abstract has no citations; acronyms expanded in abstract and again in body.
- [ ] Section headings 12 pt bold caps centered; subsections 12 pt italic Title Case left; third-level 10 pt bold run-in with Em Space.
- [ ] No column break after a heading; no orphan/widow single lines across columns.
- [ ] Figure captions below, table captions above; numbering ascending; "Figure N:" with colon; caption font 10 pt normal.
- [ ] Full-width figures/tables only at top or bottom of page, inside one-column continuous sections.
- [ ] Fig./Figure, Eq./Equation, Table usage correct; no sentence starts with an abbreviation or number.
- [ ] Equations numbered only if referenced, number right-flush in parentheses.
- [ ] Units upright with non-breaking space; singular in compound adjectives.
- [ ] Footnotes in text boxes, 8 pt, never Word footnotes; symbol marks on page 1 (column 1) only for title/author notes.
- [ ] CONCLUSION precedes ACKNOWLEDGEMENTS / APPENDIX / REFERENCES.
- [ ] Source files (text + figures) prepared for submission with the PDF.
- [ ] Word "Embed fonts in file" on; Acrobat "Add Links" on if using PDFMaker.
